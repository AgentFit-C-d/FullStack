# 풀스택 B 최종화 기준 비교 — 2026-10-25

## 코드 기준

- `origin/develop`의 `a4730aa`에서 `feat/fullstack-b-finalization`을 생성했다. Phase 3는 이미 `develop`에 병합돼 있다.
- 기존 `demo`의 추가 커밋 27개는 `develop`의 직계 후속이었다. 프론트엔드와 Core/AI 연결 변경을 새 브랜치에 fast-forward로 반영했다. 기존 `demo` 작업 폴더의 미추적 자료는 옮기거나 삭제하지 않았다.

## 기능별 대조

| 영역 | 반영된 동작 | 남은 경계 |
| --- | --- | --- |
| 인증·프로젝트·기획 | GitHub 세션, 프로젝트 생성/조회, 기획 자료 저장, AI 분석, DRAFT 편집·확정 | `/demo` 단계별 화면은 메모리 시연이다. 실제 DB 연결 화면은 `/app/live`다. |
| 역할·환경·추천 | 사용자 선언 입력 저장, AI 필요 기능 분석, Core의 승인 카탈로그 조합 판정, 최신 추천과 `STALE` 표시 | 현재 추천 도구는 합성 데모 카탈로그다. skills.sh 수집 항목은 미검증 후보이며 자동 승인·추천하지 않는다. |
| 권한·설정 | 선택, 기존 파일 텍스트 비교, Preview, 승인, ZIP, 이력 | 기존 파일의 자동 병합과 실제 설치 성공 검증은 없다. |
| 추가 질문 | 질문별 답변 저장·재조회 | 답변은 기록이며 확정 기획/환경이나 재추천 입력에 자동 반영되지 않는다. 현재 입력이 바뀌어 추천이 만료되면 답변 저장을 거부한다. |

## 이번 최종화 보완

- 추가 질문 답변 저장은 최신 추천 ID뿐 아니라 **현재 입력 basis**와 `NEEDS_INFORMATION` 상태를 확인한다. 이전 입력의 추천에는 답변을 추가하지 않는다.
- `/app/live`는 만료된 추천의 질문을 읽기 전용으로 보여주고, 새 추천 생성 후 답변하도록 안내한다.

## 검증과 제한

- Java 회귀 테스트 `RecommendationQuestionAnswerTest`: 2개 통과. 로컬 JDK 24로 Java 21 대상 코드를 컴파일했다. 실제 운영용 Java 21과 PostgreSQL 종단 경로는 이번 점검에서 다시 실행하지 않았다.
- 프론트엔드: `npm test` 93개 통과, `npm run lint`, `npm run build` 통과.
- Docker Desktop 엔진이 현재 응답하지 않아 컨테이너 기반 브라우저 종단 시연은 이번 최종화에서 재실행하지 않았다. 기존 시연 기록은 [프론트 기능 점검](frontend-demo-gap-audit-2026-10-18.md)과 [질문·파일 비교 기록](question-answer-and-existing-file-demo-2026-10-19.md)에 있다.
