## 실행 증거

- 전체 Core API Java 테스트: `mvn -q test` 성공. 별도 AI 모의 서버 테스트는 현재 AI 요청의 `facts` 계약에 맞게 바로잡았다.
- 별도 FastAPI와 격리 PostgreSQL을 사용한 B 종단 테스트: AI `needs` → 일반 추천 저장 → Preview → 사용자의 선택 Capability 재추천 저장 → Preview 성공. 격리 스키마는 테스트 종료 시 삭제했다.
- 프론트엔드: 테스트 100건, lint, Vite build 성공.
- 실제 skills.sh 공개 검색·다운로드 응답을 확인했다. 로그인된 `/app/live` 화면에서 실시간 후보 검색과 선택한 후보의 ZIP 다운로드를 실행했다.
- 로컬 Docker Compose의 Core API·AI·웹·PostgreSQL 컨테이너가 기동한 상태에서 화면을 확인했다.

## 계약과 운영 한계

현재 검색 코드는 skills.sh의 문서화되지 않은 공개 검색·다운로드 경로를 사용한다. 실제 응답은 확인했지만 안정적인 공식 API 보장은 없다. 공식 문서의 API는 Vercel OIDC 인증을 요구한다. 검색 장애는 `SKILL_SOURCE_UNAVAILABLE`로 처리하고, 기존 승인 카탈로그 추천은 별도로 유지한다.

skills.sh의 수집·보안 스캔은 AgentFit의 OS·Claude Code 버전·권한·조합 검증을 대신하지 않는다. 사용자가 직접 고른 미확인 후보는 별도 ZIP으로 제공되며, 승인 카탈로그 추천·Preview·설정 ZIP에 자동 편입되지 않는다. 이는 FSB-03의 “카탈로그 밖 도구를 추천에 통과시키지 않는다”는 조건을 지킨다.

## 다음 제품 검증

1. 실제 사용 대상 15~20종을 정해 Client 버전, OS, 설치·호출, 인증, 권한, 조합을 항목별로 기록하고 카탈로그를 확장한다.
2. A의 실제 사용자·프로젝트와 AI의 다양한 응답에서 일반/선택/미충족/정보 필요 추천을 각각 실행한다.
3. 다운로드한 설정을 대상 Client에 적용해 설치·인증·실행·복구 결과를 도구별로 확인한다.
