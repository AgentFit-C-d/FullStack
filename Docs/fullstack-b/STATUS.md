2026-11-02 질문 답변 연결: B 환경 질문 3종(`environment.target`, `environment.installedComponents`, `environment.installedComponentVersions`)에 구조화 입력을 적용해 환경 Profile·버전·답변 이력·Audit를 한 저장 경로로 연결했다. 변경 후 기존 추천은 STALE로 읽히며 사용자가 새 추천을 실행한다. 화면에는 각 질문에 맞는 입력칸을 제공한다. 실제 PostgreSQL 테스트에서 Client 대상 답변 저장→환경 버전 변경→답변/Audit 저장→기존 추천 STALE→동일 이전 답변 거부를 확인했다. 다른 두 답변 형태와 실제 AI 재추천 HTTP 종단은 추가 확인 대상이다. 기획 관련 질문은 기존 확정 화면에서 수정해야 하며 이 답변 API에서 Profile을 직접 수정하지 않는다.

PRD의 FSB-01~12 영역 모두 관련 구현이 있지만, 모든 수용 조건을 충족한 상태는 아니다. 과거 내부 체크리스트의 4/12는 현재 완료율로 사용하지 않는다. 테스트 수를 제품 완성률로 환산하지 않는다.

- 구현된 주요 경로: 확정 기획 조회, 역할·환경 저장, 카탈로그 판정, 일반/선택/부분 추천, 권한 선택, 미리보기·Diff, 승인·ZIP, 이력·사용자 적용 보고, 프로젝트 삭제.
- skills.sh 검색·후보 ZIP도 존재한다. 다만 검색 후보가 자동으로 기본 추천 카탈로그에 편입되는 구조는 아직 아니다.
- 새 분석 화면의 검토 저장과 기존 기획 확정·B 추천 화면은 별도 경로다.
- 질문 답변은 저장되지만 원천 기획·환경 변경/재추천 입력에는 자동 반영되지 않는다.
- 환경 입력의 미정 버전, 런타임/인증 정보, 정규화·한도·Audit는 1차 계약과 차이가 있다.
