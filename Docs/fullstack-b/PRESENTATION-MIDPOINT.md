# 중간 프로젝트 발표용 — 풀스택 B

> 2026-10-07 기준. 슬라이드에 바로 옮길 수 있는 문구이며 **구현된 내부 검증**과 **아직 연결되지 않은 실제 사용자 흐름**을 구분한다. 팀 공통 발표 자료에서는 A·AI 담당 성과와 중복되지 않게 B 담당 범위만 사용한다.

## 슬라이드 1 — 담당 범위와 설계 원칙

**제목:** “검증된 도구만 추천하고, 확인한 설정만 내보내는 B 영역”

**흐름:** 확정 기획·역할·환경(A) → Capability 후보(AI) → **Catalog 검증·추천·권한·Preview·ZIP(B)** → 화면·적용 안내

- Spring Boot `core-api`가 지원 여부·호환 조합·권한·최종 추천을 판정한다. FastAPI는 Capability와 설명의 후보를 만들며 PostgreSQL에 직접 접근하지 않는다.
- 정확한 OS·Client·버전과 단독/조합 검증이 없는 도구는 추천에 넣지 않는다. 권한 기본값은 검증된 `ASK_EACH_TIME`이며 사용자의 선택을 설치 완료로 표시하지 않는다.
- 첫 실 Catalog 대상은 **Claude Code**이고 Codex는 후속이다. 현재 테스트의 `example-client`는 합성 fixture다.

## 슬라이드 2 — 지금 구현·검증한 결과

**제목:** “추천부터 승인된 ZIP까지의 내부 안전장치”

1. **추천:** 고정 9개 Capability와 네 결과를 판정한다. AI 평가의 중복·미지 키·허용 밖 근거를 거부하고, 9개 중 누락된 항목을 ‘필요 없음’으로 오해하지 않도록 막는다. 설치 버전·OS·Client·의존성·충돌·검증 조합을 함께 검사한다.
2. **Catalog·권한:** 릴리스 파일의 SHA-256·스키마·근거·대상별 지원·권한 매핑을 검사한다. 미검증 조합과 미지원 정책은 차단한다.
3. **Preview·다운로드:** 승인 Catalog의 고정 템플릿만 비교하고, 원본·Diff는 일시 처리한다. 현재 기획/환경 버전과 Preview 지문·승인·만료를 재검사한 뒤 ZIP을 재생성하며, 파일 내용 대신 최소 생성 이력만 반환한다. ZIP에서 파일과 상위 폴더가 충돌하는 경로도 차단한다.

**검증 수치:** 최근 `core-api` 전체 `mvn clean verify`에서 **119개 발견, 118개 통과, Windows 심볼릭 링크 시험 1개 건너뜀**. JDK 24에서 Java 21 대상 컴파일·테스트를 확인했으며 Java 21 런타임 실행은 아직 검증하지 않았다.

## 슬라이드 3 — 실제 서비스 연결까지 남은 일

**제목:** “도메인 검증 코드는 준비, 사용자 흐름 통합은 진행 전”

| 완료 판단 | 현재 상태 | 다음 연결 |
| --- | --- | --- |
| B01–B04 도메인 기반 | 완료 | 기존 검증 유지 |
| B05–B07 A·AI 및 읽기 API | 미완료 | A의 인증·현재 스냅샷/DB 계약, AI의 9개 Capability 성공·실패 응답 계약 |
| B08 실제 Claude Code Catalog | 미완료 | 후보 도구·고정 버전·OS 범위, 단독/조합/권한 시험, 독립 승인 hash |
| B09–B12 사용자 선택·Preview·승인·이력 | 내부 검증 일부 구현, 엔드투엔드 미완료 | 현재값 재조회·저장 트랜잭션·API/화면·삭제 통합 시험 |

**진행 표기:** B01–B12 상위 목표 **4/12 완료(33.3%)**. 이는 체크리스트 완료 비율이며 제품 완성도나 사용자 이용 가능 비율을 뜻하지 않는다. 실제 Claude Code 지원·DB 저장·인증된 API·FastAPI 연동은 아직 완료되지 않았다.

## 30초 발표 멘트

“저는 풀스택 B로서 Catalog, 추천, 권한, 설정 생성 영역을 맡았습니다. 지금은 AI가 제안한 Capability를 그대로 설치 추천으로 쓰지 않고, 검증된 도구·환경·조합과 권한을 Spring Boot에서 다시 판정하는 코드를 만들었습니다. Preview 내용과 승인된 ZIP의 지문이 일치하는지도 검사하고 있습니다. 현재 내부 검증은 119개 테스트 중 118개 통과, 1개는 Windows 권한 때문에 건너뛰었습니다. 상위 목표 12개 중 4개가 완료된 상태이며, 다음 단계는 A의 인증·저장 계약과 AI 응답 계약을 연결하고 실제 Claude Code Catalog를 검증하는 것입니다.”

**발표에서 피할 표현:** “서비스 전체 완성”, “Claude Code 도구 15~20개 지원”, “AI 연동 완료”, “설정 자동 적용”, “119개 테스트 전부 통과”. 현재 근거는 내부 도메인/메모리 경계와 합성 Catalog 시험이다.
