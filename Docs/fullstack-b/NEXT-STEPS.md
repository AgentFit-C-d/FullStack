# 풀스택 B 다음 작업 — 통합 develop 기준

A는 이미 병합됐고 AI 구현도 준비돼 있다. 외부 팀 코드가 없어서 기다리는 단계가 아니다. 아래는 2026-11-02 코드 대조에서 확인한 수정·연결 작업이다.

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 로컬·Docker 추천 AI 주소와 카탈로그 마운트 정렬 | 주소·루트 Compose 카탈로그 마운트 반영. 실제 컨테이너 종단 확인은 남음 |
| 2 | 환경·역할 입력 계약 보완 | 미정 버전·목록 30개·정규화 중복·code points 반영. 런타임·인증 정보 및 Audit 원자 저장은 남음 |
| 3 | 추가 질문 답변 coordinator 연결 | B 환경 질문 3종의 원천 환경·버전·Audit 갱신 구현. Client 대상 답변 PostgreSQL 확인 완료. 나머지 두 형태의 DB 사례와 실제 AI 재추천 HTTP 종단, 기획 질문의 확정 경로 연계는 남음 |
| 4 | 새 분석 검토 → 확정 → B 흐름 연결 | humanReview의 사용자 수정이 확정본에 반영되고 동일 프로젝트로 역할·환경·추천 진행 |
| 5 | 별도 AI needs/rank와 skills.sh 후보의 추천 편입 | 출처·내용 버전·기능/조건을 정규화하고 내부 조합 판정 뒤 추천·선택·설정으로 연결 |
| 6 | 실제 도구 지원 범위 확대 | 추천 대상별 환경·권한·설정·적용 안내를 갖추고 실제 지원 범위를 표시 |

현재 확인된 사실과 파일 근거는 [통합 후 B 기능 대조](integration/develop-b-requirements-audit-2026-11-02.md)에 정리했다. 단순 팀 승인 대기는 현재 차단 사유로 두지 않으며, 미확인 호환성·실행 결과를 확인한 것으로 꾸미지도 않는다.

신규 DB 마이그레이션은 검증됐다. 과거 B의 옛 V7이 적용된 DB는 별도 이력 확인이 필요하며 자동 repair/초기화하지 않는다.

이전 인계 계획은 [과거 기록](NEXT-STEPS-HISTORY-2026-10-28.md)으로만 보존한다.
