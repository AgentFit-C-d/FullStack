# 9주차 발표 — 추천 근거·제약사항 보완

> 2026-10-27 코드와 로컬 검증 기록 기준. 기존 추천 흐름 소개 이후의 구현 진척을 설명한다.

## 슬라이드 1 — 추천 근거와 검토 정보

**제목:** 추천 결과를 판단할 수 있는 근거 보완

| 보완 항목 | 현재 구현 |
| --- | --- |
| 추천 이유 | 충족 기능과 현재 환경의 Catalog 지원 기록을 연결해 도구별로 표시 |
| 검토 정보 | 도구 출처·필요 권한·위험도와 외부 인증의 검토 상태를 표시. 검토 전이면 그대로 표시 |
| 이력 | 추천 당시 이유·버전·위험도 검토 상태를 저장해 이후에도 조회 |

**발표 멘트:** “추천 결과에 어떤 기능을 충족하는지와 현재 환경에서의 지원 근거를 붙였습니다. 출처와 권한을 함께 보여주고, 위험도나 외부 인증이 검토되지 않은 도구는 검토 전이라고 표시합니다. 추천 당시의 설명도 저장해 나중에 확인할 수 있습니다.”

## 슬라이드 2 — 실제 AI 응답에 대한 부분 추천

**제목:** 충족한 기능과 부족한 기능을 함께 표시

| 실제 검증 단계 | 확인 결과 |
| --- | --- |
| 확정 기획 항목 | `Write tests` |
| FastAPI needs 응답 | 테스트 작성과 테스트 실행을 모두 필수로 판정 |
| 로컬 검토 Skill | 테스트 작성만 지원 |
| B 결과 | 부분 추천 1건과 `partial_required_coverage` 경고 저장 |
| 설정 미리보기 | 테스트 실행을 미충족 기능으로 표시 |

**발표 멘트:** “실제 AI 응답을 연결하니, 기획에서 필요한 기능과 검토된 도구의 지원 범위가 달랐습니다. 이 사례에서는 테스트 작성 도구를 부분 추천하되 테스트 실행은 부족하다고 표시했습니다. 이 판정과 경고가 PostgreSQL 저장과 미리보기까지 유지되는 것을 격리 테스트로 확인했습니다.”

**표기할 검증 범위:** 실물 Skill의 Windows·Claude Code 로컬 검토 결과다. 팀의 독립 승인과 운영 Catalog 적용은 아직 완료되지 않았다. 별도 AI 저장소와 Core 간 분석 계약도 완전히 정렬되지 않았다.
