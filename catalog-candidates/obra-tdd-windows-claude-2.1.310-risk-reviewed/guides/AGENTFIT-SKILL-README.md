# Test-driven-development Skill for Claude Code

Source: https://skills.sh/obra/superpowers/test-driven-development

The two files in `.claude/skills/test-driven-development/` were fetched from
skills.sh as one pinned snapshot. The exact upstream hash is in
`SUPERPOWERS-SKILL-HASH.txt`. The upstream MIT license is included.

Copy the `.claude/skills/test-driven-development/` directory into the root of
your Claude Code project. Restart Claude Code, then invoke
`/test-driven-development` when working on a feature or bug fix.

This Skill contains instructions, not an executable installer or an MCP server.
It does not grant file edit or test command permission. Claude Code still asks
according to the user's own permission settings. Review the generated files
before copying them into a project.

Supported Catalog target: Windows, Claude Code 2.1.310. Other clients,
operating systems, or versions are not covered by this verification record.
