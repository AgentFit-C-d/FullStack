# Playwright MCP 로컬 적용 안내 초안

이 파일은 Windows와 Claude Code 2.1.270에서 조사한 `@playwright/mcp@0.0.83` 후보의 안내 초안입니다. AgentFit의 지원·권한·조합 검증과 독립 릴리스 승인은 아직 끝나지 않았습니다. 이 파일을 받았다는 사실은 설치나 동작 확인을 뜻하지 않습니다.

## 적용 전 준비

1. Node.js 18 이상과 사용할 브라우저가 준비됐는지 확인합니다.
2. 설치할 패키지의 출처와 고정 버전 `@playwright/mcp@0.0.83`을 직접 확인합니다. `@latest`로 바꾸지 않습니다.
3. 외부 사이트 접근과 브라우저 조작을 허용할 범위를 먼저 정합니다. 조사 중 도구 목록에 `browser_run_code_unsafe`가 있어 전체 도구를 일괄 허용하지 않습니다.

## 로컬 시험 범위

격리된 Claude Code 실행에서 임시 MCP 설정과 `--strict-mcp-config`를 사용해 로컬 `data:` 페이지의 제목과 접근성 스냅샷을 확인했습니다. 사용자나 프로젝트의 지속 설정에 서버를 추가하지 않았습니다. 실제 업무 사이트, 인증 계정, 쓰기 작업, 장애 복구는 검증하지 않았습니다.

## 적용과 확인

제품용 설정 명령과 파일은 권한 매핑·정확한 Client 동작 검증 후 제공해야 합니다. 지금은 이 초안을 설치 명령으로 실행하거나 사용자 설정에 복사하지 마세요. 검증된 릴리스가 제공되면 해당 버전의 적용 위치와 권한을 확인하고, 먼저 인증이 필요 없는 무해한 로컬 페이지 탐색으로 연결 상태를 점검하세요. 연결 성공은 실제 사이트 접근 권한이나 안전한 브라우저 조작의 증거가 아닙니다.

## 되돌리기

시험에 사용한 임시 MCP 설정과 격리 설치 폴더를 제거하고 Claude Code를 새로 시작합니다. 기존 사용자·프로젝트 MCP 설정을 변경하지 않았다면 복구할 지속 설정은 없습니다. 실제 릴리스의 설정을 적용한 뒤에는 해당 릴리스가 제공하는 제거 절차를 따릅니다.
